🎬 Premiere Pro Extension

Integrate your entire EditFlow workspace natively inside Adobe Premiere Pro (Windows). Follow these steps to install the extension.

1

Download & Extract

Click the download button below to get the editflow-premiere-extension.zip file and unzip it.

2

Copy to Extensions Folder

Copy the unzipped folder online.acsoft.editflow.premiere and paste it into:
Path A: C:\Users\<Username>\AppData\Roaming\Adobe\CEP\extensions\
Path B (Recommended if A fails): C:\Program Files\Common Files\Adobe\CEP\extensions\

3

Enable Unsigned Extensions

Double-click the enable-debug-mode.reg file inside the folder, click Yes and then OK to automatically allow local extensions.

4

Launch Panel & Troubleshoot

Open Premiere Pro -> Go to Window > Extensions > EditFlow OS.
Tip: If other extensions show up but EditFlow doesn't, make sure to restart your PC or end all CEP HTML Engine background processes in Task Manager, then restart Premiere Pro to force a directory re-scan.
